<p align="center">
  <b>We are working on a protocol for AI agents that work side by side.</b>
</p>

<p align="center">
  When several agents touch the same project, somebody has to keep track of who owns what,<br>
  what was agreed between them, and which evidence backs a finished piece of work.<br>
  That is the problem we are building for.
</p>

<br>

<table align="center">
<tr>
<td align="center" width="33%">

### Ownership

Clear territory for each agent, so two of them never overwrite each other's work.

</td>
<td align="center" width="33%">

### Agreements

Shared decisions, recorded where every participant can read them, with a trail of who changed what.

</td>
<td align="center" width="33%">

### Evidence

A result counts as done only when the checks behind it are attached to it.

</td>
</tr>
</table>
